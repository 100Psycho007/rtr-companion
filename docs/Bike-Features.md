# Bike Features

## Observed from the RTR 310 manual

The manual lists many connected and rider-assistance features, including:

- Connected TFT instrument cluster
- Menu function
- Ride modes
- Trip details
- My vehicle
- Preferences
- TVS Connect App
- Bluetooth pairing
- Voice Assist
- Digi Docs
- TPMS
- Climate Controlled Seat
- Cruise control
- Traction control
- Wheelie mitigation
- Cornering ABS
- Cornering traction control
- Slope dependent control
- Rear lift protection

## Note

These features are part of the bike's built-in system and may not all be controlled through the phone app. The documentation here should be updated only with behavior that has been observed directly.
