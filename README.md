# RTR Companion

Open-source Android companion app and Bluetooth SDK for the TVS Apache RTR 310.

## Goal

Build a clean, documented foundation for Bluetooth discovery, protocol research, and future app features.

## Project structure

- `app/` – Android app
- `smartx-sdk/` – Bluetooth communication library
- `docs/` – protocol notes, screenshots, and research
- `captures/` – packet captures and logs
- `tools/` – scripts and helpers

## Current status

- Repository initialized
- Environment setup in progress
